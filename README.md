# Landing Page Portfolio

Editorial single-page portfolio (Next.js, SCSS, GSAP, Lenis).

## About Me

I'm Aditya Dutta, a Senior UI Developer based in Noida, India, with more than seven years of experience in frontend development and web design. I build responsive, accessible, and high-performance web applications with React.js, Next.js, TypeScript, JavaScript, and Sass.

## Stack

- Next.js (App Router) + TypeScript
- SCSS (no Tailwind)
- GSAP + Lenis
- Light / dark theme via CSS variables

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3800](http://localhost:3800).

## Content

Edit `src/data/animatedView.ts` for profile details, experience, skills, and contact information.

## Cross-link (Vercel)

Set `NEXT_PUBLIC_JOURNEY_URL` to the production Journey site URL (no trailing slash). See `.env.example`. Changing this on Vercel requires a redeploy.
